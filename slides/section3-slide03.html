FLASK PROJECT

Un proyecto Flask típico organiza el código en módulos para APIs, configuración, y lógica de negocio. Usa entornos virtuales para gestionar dependencias. 

flask-api-project/
├── venv/                 # Entorno virtual Python
├── app/
│   ├── __init__.py      # Inicializa Flask app
│   ├── routes.py        # API endpoints
│   └── services.py      # Lógica de negocio
├── requirements.txt     # Dependencias (Flask, etc.)
├── .env                 # Environment variables
└── run.py               # Entry point
