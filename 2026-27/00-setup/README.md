# 00 — Setup & mental model

## Learning goals

- Navigate the file system and run commands in a terminal.
- Version work with git and publish it on GitHub.
- Explain what happens between typing a URL and seeing a page (client, server, HTTP, DNS).
- Describe what a coding agent is: a model in a loop that reads files, runs tools and edits code.

## Session plan (draft)

1. How the web works; the developer's toolbox.
2. Terminal and git, hands-on.
3. Install the agentic IDE; first conversation with an agent *about* the repo (ask, don't build).
