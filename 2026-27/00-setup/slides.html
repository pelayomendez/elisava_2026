Why we work this way

Software is an apprenticeship industry — you can only learn by doing. The industry changes fast, so developers have to keep learning. It takes many years to forge a competent software engineer.

Senior software engineers don't only write code — they have to be able to understand, maintain, explain, and manage a large body of software in production over time and translate business needs into technical implementation.

Writing code is the easiest part of software engineering, and it's getting easier every day. AI can help generate lots of code really fast, but it can't aid in the work of managing, understanding, or operating that code.

Generated code can't be trusted — it needs to be reviewed before it can be committed and shipped to production.

How the web works

From a URL
to a page

  1. URLYou type an address in the browser.
  2. DNSThe name becomes a server's address.
  3. HTTPThe browser asks; the server answers with HTML, CSS, JS.
  4. RenderThe browser builds and paints the page.
Steps 1–3 are the client–server pattern. The next slides open it up.
The client–server pattern

One asks,
one answers

ClientYour browser, an app, a script
RequestGET /pokemon/25
Response200 OK · JSON / HTML
ServerA computer that is always on, waiting
The client always starts the conversation. The server never calls you first — it only answers. (Chapter 08 shows the exceptions.)
Who does what

Split the work,
split the trust

Client

  • Shows the page and reacts to clicks
  • Runs HTML, CSS and JavaScript
  • Anyone can read and change it: never trust it
  • No secrets here — not even API keys

Server

  • Stores the data and the files
  • Runs the rules: who can see or change what
  • Keeps the secrets: keys, passwords
  • Answers many clients at once

A request is
just text

# the client sends

Host: pokeapi.co
Accept: application/json
# the server answers
HTTP/1.1 200 OK
Content-Type: application/json

{ "name": "pikachu", "id": 25, … }

Method

GET read · POST create · PUT/PATCH change · DELETE. More in chapter 06.

Path

What you want: /pokemon/25

Headers

Extra info: format, auth, cache

Status

200 ok · 404 not found · 500 server broke
