# 09 — Final project

## Brief (draft)

Design and build a small web product of your own, end to end, with an agentic workflow.

## Deliverables

- Deployed site and repository with a readable history of small commits.
- `spec.md`: goal, users, constraints, acceptance criteria, edge cases.
- `AGENTS.md` and any skills or MCP servers used.
- Review log: what the agent proposed, what you rejected and why.
- **Oral defence:** walk through one diff and explain every line; change something live without the agent.
