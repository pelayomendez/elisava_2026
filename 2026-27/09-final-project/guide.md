# Guide — Final project

> Draft. Templates for the final deliverables.

## 1. `spec.md` template

The product-level brief. Each feature then goes through OpenSpec as its own change: see
[Spec-driven development with OpenSpec](../03-spec-driven-development/guide.md).

```markdown
# <Product name>

## Goal
One sentence: what it does and for whom.

## Users
Who uses it and what they already know.

## Constraints
Stack, design system, hosting, budget, time.

## Acceptance criteria
- [ ] …

## Edge cases
- …
```
