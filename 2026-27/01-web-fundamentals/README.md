# 01 — Web fundamentals, hand-made

## Learning goals

- Write semantic HTML, layout with Flexbox and Grid, and use CSS variables.
- Fetch data from an API and update the DOM with JavaScript; handle events.
- Deploy a static site on GitHub Pages.
- Read agent-written HTML/CSS/JS critically: spot what's wrong, redundant or inaccessible.

## Session plan (draft)

1. HTML + CSS: build the Pokédex layout **without an agent**.
2. JavaScript: fetch the PokéAPI, render, filter by type — still no agent.
3. **Rebuild & compare:** write an `AGENTS.md` as the brief and have an agent build the same Pokédex from it; diff it against your version and explain each difference.
