HTML

Structure
with meaning

<header>
  <nav>…type filters…</nav>
</header>
<main>
  <div id="list"></div>
</main>

Semantic tags tell browsers, screen readers — and agents — what each part of the page is.

CSS

Design as
variables

:root {
  --clr-black: #1c1c1c;
  --clr-fire: #F08030;
}
#list {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(200px, 1fr));
  gap: 1rem;
}

Variables are your design tokens. Grid and Flexbox do the layout. Same ideas you'll ask an agent to respect later.

Reuses: 2025-26 · CSS3 styling · Guides: CSS basics, CSS architecture
JavaScript

Data into
the page

const res = await fetch(
  "https://pokeapi.co/api/v2/pokemon/1"
);
const poke = await res.json();

const card = document.createElement("div");
card.textContent = poke.name;
list.append(card);

Ask an API, get JSON, turn it into elements. This loop is the heart of every web app.

Events

React to
the user

buttons.forEach(btn =>
  btn.addEventListener("click", () => {
    showOnly(btn.id); // "fire", "water"…
  })
);

Filters by type: listen for a click, change what's on screen.

with an agent
