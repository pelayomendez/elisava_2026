# 06 — Data

## Learning goals

- Consume and design REST APIs; understand HTTP verbs and status codes.
- Model data in SQL and NoSQL; write basic queries.
- Persist and sync data with Supabase (CRUD, auth basics, realtime).
- Let an agent inspect a database through MCP — and know what to forbid it.

## Session plan (draft)

1. APIs and data flow on the client.
2. SQL vs NoSQL; Postgres; when to use what.
3. Supabase: CRUD and realtime; favourites for the Pokédex.
4. Same app, different backends (mock / Postgres / Mongo / Supabase).
