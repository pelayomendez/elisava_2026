# 08 — Realtime & agents as product

## Learning goals

- Compare polling, webhooks, SSE and WebSockets and pick the right one.
- Build a realtime client with Socket.IO.
- Program an autonomous client-side agent (Agent Wars phase 3).
- Automate with workflows (n8n) and build a background agent with memory.

## Session plan (draft)

1. The realtime spectrum: live SSE / webhooks / WebSockets demo.
2. Agent Wars phases 1-2: connect, move, repair.
3. Agent Wars phase 3: autonomous agent; PR submission.
4. Workflows and background agents: n8n alert, Better Me Agent.
