# 04 — Design to code

## Learning goals

- Turn a Figma design into components, by hand and via the Figma MCP server.
- Use Tailwind v4 and a component library; compare with vanilla CSS.
- Have a browser-driving agent check layout, responsiveness and accessibility.

## Session plan (draft)

1. Figma → HTML/CSS by hand (tokens, spacing, type).
2. Figma MCP: same design generated by the agent; review against the design.
3. Tailwind v4 vs vanilla vs Flowbite; theming.
4. Verify with the browser: screenshots, Lighthouse, accessibility.
