Webhook Subscriptions

Webhooks = HTTP POST callbacks. Register a URL, and the server sends events to it. Server-to-server, fire and forget.

POST /api/webhooks/register { "url": "https://...", "events": ["order.completed"] } → Server POSTs to your URL when events fire
