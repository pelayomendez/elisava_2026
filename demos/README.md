# Demos

Small classroom demos. Each folder is self-contained; run `npm install` first (dependencies are not committed).

- `sse-ws-server/` - Express server for comparing Server-Sent Events, webhooks and WebSockets live in class (package description: "Interactive demo showcasing SSE and Webhooks").
- `n8n-temperature-alert/` - Astro client posts a device temperature to an n8n workflow (local Docker or n8n Cloud webhook) that evaluates it and emails an alert on warning/critical readings.
- `tailflow-demo/` - Astro + Tailwind + Flowbite pages comparing vanilla Tailwind with Flowbite components, centering and theming (its README is the unmodified Astro starter text).
- `figma-html/` - Minimal HTML/CSS/JS page (button plus Pokemon fetch) used as a Figma-to-HTML exercise starting point (no README in the source).
- **autonomous-game-studio** — Astro site where an AI generates a game from a brief, with votes (Mistral).
