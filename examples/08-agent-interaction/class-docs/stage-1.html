Stage 1

The agent is just a contract.

Before any backend or UI exists, we define the agent with five simple markdown files. This makes the behavior readable, teachable, and easy to revise.

Files

What we define

  • AGENTS.md for instructions and tone
  • TASK.md for the output format
  • MEMORY.md for user context
  • TOOLS.md for capabilities and limits
  • EVALS.md for success criteria

Why It Matters

The agent starts as product thinking

This stage is useful in class because students can read and critique the agent behavior before any code obscures the idea.

The key lesson: an agent does not start as a model call. It starts as a contract.

Teacher Notes

What to say in class

Start with AGENTS.md This is the personality, safety boundary, and tone.
Then TASK.md This is the output contract the runtime will later enforce.
Then MEMORY.md This is where personalization begins.
End with EVALS.md This is what “good” means for the agent.
