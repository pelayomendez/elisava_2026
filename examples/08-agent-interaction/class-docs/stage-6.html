Stage 6

One spec, two apps, one backend.

This stage shows the simplest final product: a desktop React app and a React Native app that both talk to the same deployed Cloudflare backend.

Product rule

Thin clients

  • Fetch memory from the Worker
  • Fetch recent runs from the Worker
  • Send a manual message with /agent/run
  • Trigger a reminder with /agent/notify

Backend URL

Use the deployed Worker
