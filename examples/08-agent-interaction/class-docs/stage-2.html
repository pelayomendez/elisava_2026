Stage 2

The markdown contract becomes a backend.

This stage reads the contract files, builds a prompt, calls Mistral, and exposes a simple FastAPI endpoint for testing.

Core idea

Prompt assembly

The runtime loads AGENTS.md, TASK.md, MEMORY.md, TOOLS.md, and EVALS.md, combines them into one prompt, and sends the result to the model.

Endpoints

Simple API

  • GET /health
  • POST /agent/run
