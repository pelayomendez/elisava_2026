Stage 3

The agent becomes a real interactive app.

This stage connects a frontend to a live AG-UI runtime so users can chat with the agent and see streaming activity.

Why It Matters

Streaming is visible

Instead of only seeing a final response, the UI can show that the agent started, thought, ran steps, and finished.

Stack

Frontend and backend

  • React + Vite
  • CopilotKit UI
  • FastAPI + LangGraph
  • AG-UI endpoint at /copilotkit
