Stage 5

Deploy the agent to Cloudflare.

This is the cloud backend that powers the final apps. By default it behaves like a normal hosted API first, with cron left off until later.

Worker runtime D1 database Public API URL

Setup

Cloudflare install flow

cd /Users/pomf/Experimental/elisava_temp/agent-interaction/stage-5-cloudflare-worker/better-me-agent/cloudflare
npm install
npx wrangler login
npx wrangler d1 create better-me-agent-db

Then paste the printed database_id into wrangler.jsonc.

Initialize D1

Remote schema

npx wrangler d1 execute better-me-agent-db --remote --file=./schema.sql

Secrets

Production values

npx wrangler secret put MISTRAL_API_KEY
npx wrangler secret put SLACK_WEBHOOK_URL

Deploy

Publish the Worker

npx wrangler deploy

About Cron

Disabled first, enabled later

The Worker already includes a scheduled() handler, but the default configuration does not enable cron yet. This keeps the backend simple while the apps are being connected. 

"triggers": {
  "crons": ["*/5 * * * *"]
}

Add that back to wrangler.jsonc later if you want the loop.

Important teaching point: the app never talks directly to D1. It only talks to the Worker API.
