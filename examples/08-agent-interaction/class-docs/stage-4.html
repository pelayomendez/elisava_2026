Stage 4

The agent becomes proactive.

Instead of waiting for a user message, the same coaching agent can wake up on a schedule, generate a reminder, log the run, and send the result to Slack.

Two processes

Server and worker

  • uvicorn for manual API testing
  • background_agent.py for repeated scheduled runs

Delivery

Slack as notification channel

Slack is easier to demo than local Apple notifications because delivery is more reliable.

Run The API

Manual mode

cd /Users/pomf/Experimental/elisava_temp/agent-interaction/stage-4-background-agent/better-me-agent/backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
uvicorn main:app --reload --port 8000

Manual Slack test

Notify once

curl -X POST http://localhost:8000/agent/notify \
  -H "Content-Type: application/json" \
  -d '{"message":"Send me a small habit reminder for this afternoon"}'

Worker mode

Loop every 5 minutes

cd /Users/pomf/Experimental/elisava_temp/agent-interaction/stage-4-background-agent/better-me-agent/backend
